
# Shramico Website

The **Shramico Website** is the official online presence for the Shramico mobile application. It serves as a premium landing page, support portal, and information hub for employers, workers, and partners.

Visitors can learn about the platform, explore its features, access support resources, review legal policies, and download the mobile application from the Google Play Store.

## 🌐 Purpose

* Showcase the Shramico platform and its capabilities
* Provide an official support website for users
* Offer access to Privacy Policy and Terms & Conditions
* Answer common questions through an FAQ section
* Provide contact information for support and business inquiries
* Redirect users to download the Shramico mobile app from Google Play

## ✨ Key Features

* Premium, responsive design
* Mobile-first user experience
* Elegant burgundy-themed branding
* Smooth navigation and modern UI
* Feature highlights and platform overview
* App screenshots and product showcase
* Frequently Asked Questions (FAQ)
* Contact and support section
* Privacy Policy and Terms & Conditions pages
* Direct download button linking to the Google Play Store
* SEO-friendly and accessibility-conscious implementation

## 🎨 Brand Theme

Shramico uses a sophisticated **burgundy-inspired** design language to create a professional and trustworthy user experience.

* **Primary Color:** Burgundy (`#800020`)
* **Background:** White / Soft Gray
* **Typography:** Clean, modern, and highly readable
* **Style:** Minimal, elegant, and premium without flashy effects


## 🚀 Running the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 📱 Mobile Application

The Shramico mobile app enables employers and workers to connect efficiently through a secure and user-friendly experience.

Once published, the **Download** button on the website should direct users to the official Google Play Store listing.

## 🔒 Privacy & Security

Shramico is committed to responsible handling of user information and transparent permission usage. Users should always have access to the latest Privacy Policy and Terms & Conditions through the website.

## 📞 Support

For assistance, feature requests, or business inquiries, users can reach the Shramico support team through the contact methods provided on the website.
